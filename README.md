# Visualizing the History of Nobel Prize Winners

## About
An exploratory data analysis of Nobel Prize winners from 1901 to present.
The project explores trends in gender, nationality, and category over time.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## What I Did
- Analyzed over 100 years of Nobel Prize data
- Identified trends in gender representation over time
- Explored which countries dominate certain prize categories
- Visualized patterns using charts and graphs

## Dataset
Nobel Prize winner data provided by DataCamp, originally sourced 
from the Nobel Prize official records.
